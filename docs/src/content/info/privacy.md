## What Clairvoyance does

Clairvoyance is a set of software design skills for AI coding agents. All skills run locally inside your agent's session. Clairvoyance does not operate any servers, APIs or external services.

## Data collection

Clairvoyance does not collect, transmit, or store any user data. No telemetry, no analytics, no tracking. Your code never leaves your machine through Clairvoyance.

## Third-party services

Clairvoyance has no MCP servers and no dependencies on external services. It consists of Markdown skill and agent files that run entirely within your agent session.

## Cookies

This documentation site does not use cookies or any tracking technologies.

## Changes

If this policy changes, the update will be reflected here with a new date.
