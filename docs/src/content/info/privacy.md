## What Clairvoyance does

Clairvoyance is a set of software design skills for AI coding agents. Installed as a plugin or skill pack, every skill runs locally inside your agent's session. Clairvoyance also runs one optional online service: a read-only MCP server at <https://clairvoyance.fyi/mcp>, for agents that connect to the skills instead of installing them.

## Installed skills

Installed skills don't collect, transmit, or store any user data. No telemetry, no analytics, no tracking. Your code never leaves your machine through an installed skill.

## The MCP server

If you connect an agent to the MCP server, each skill your agent loads is a request to clairvoyance.fyi. A request contains only the name of the skill, or of a skill's supporting file. The server's tools take no other input and it never receives your code, file paths or prompts. The Clairvoyance MCP server code does not store or log requests, and there are no accounts or cookies.

## Third-party services

This site is hosted on GitHub Pages with requests proxied through Cloudflare, which also runs the MCP server. Both process requests in order to deliver them, under their own policies: the [GitHub General Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement) and the [Cloudflare Privacy Policy](https://www.cloudflare.com/privacypolicy/). Clairvoyance has no other dependencies on external services.

## Cookies

This documentation site does not use cookies or any tracking technologies.
