## Bugs, questions and ideas

The best place to reach the project is its [GitHub issue tracker](https://github.com/codybrom/clairvoyance/issues). Open an issue to:

- report a skill that misfires, triggers when it shouldn't, or gives advice you disagree with
- report an installation problem on a specific agent platform
- suggest improvements to existing skills
- ask a question about how a skill works

Issues are public. When reporting a problem, include your agent platform and version, how you installed Clairvoyance and the prompt or code that produced the unexpected result.

## Email

For anything you'd rather not post publicly, including security concerns, email [esp@clairvoyance.fyi](mailto:esp@clairvoyance.fyi).

## Maintainer

Clairvoyance is maintained by [Cody Bromley](https://github.com/codybrom). Read more about the project on the [about page](/about).
