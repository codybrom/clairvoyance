## What Clairvoyance is

Clairvoyance is a free, open-source collection of software design skills for AI coding agents. AI agents have become exceptional collaborators for writing working code, but they don't stop to consider design unless asked. Each skill in Clairvoyance attempts to give your agent "extrasensory perspective" to design better software and provides concrete tests it can apply during implementation and review to avoid obstacles before it runs into them.

## Where the ideas come from

The skills are inspired by John Ousterhout's book [*A Philosophy of Software Design*](https://web.stanford.edu/~ouster/cgi-bin/aposd.php), which itself grew out of his years of building systems and teaching software design at Stanford. Clairvoyance recasts those principles for agentic development, turning them into guidance an AI coding agent can act on while it reads and writes real code. Every skill was written **by a human** with the aim of creating actually valuable guidance and not AI summarized slop.

## How it works

The skills are organized into five pillars: Structure, Abstraction, Clarity, Process and Diagnostics. Your AI agent can proactively apply them automatically when they're relevant or you can invoke them directly as needed. Every skill is a Markdown file that runs inside your agent's own session. Clairvoyance runs no servers and collects no data (see the [privacy policy](/privacy) for details).

Browse the full catalog on the [skills page](/skills), or give an agent everything at once with [llms-full.txt](/llms-full.txt).

## Where it can be used

Clairvoyance can be installed for use with Claude Code, Codex, Cursor, OpenCode, Gemini CLI, Antigravity, Factory Droid, GitHub Copilot CLI, Kimi Code, Pi or any AI or agent that supports the [Agent Skills](https://agentskills.io) open standard. You can also install skills through [skills.sh](https://skills.sh/codybrom/clairvoyance). See the [installation guide](https://github.com/codybrom/clairvoyance#installation) for instructions on how to install for your platform.
